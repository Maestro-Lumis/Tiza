# Tiza

Онлайн-доска для уроков: учитель и ученик рисуют на одном холсте и видят действия друг друга.

Текущая версия: **0.14.0**. История изменений: [CHANGELOG.md](CHANGELOG.md).

Сайт: https://maestro-lumis.github.io/Tiza/

Репозиторий: https://github.com/Maestro-Lumis/Tiza

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173.

Настройки и ключи лежат в `.env`, он в git не попадает. Образец без значений - `.env.example`:

```bash
cp .env.example .env
```

Вместе с сайтом `npm run dev` запускает и сервер доски (порт 8787): без него не войти в учётную запись. Если сервер уже запущен отдельно, второй не стартует. Запустить только сервер:

```bash
npm run server
```

Одна и та же доска, открытая в двух вкладках, показывает изменения друг друга. Сервер хранит доски в базе: у себя на компьютере это файл `data/tiza.db` (в git не попадает), на хостинге - Turso (адрес и токен в `.env`).

## Администратор

Команды запускаются у себя на компьютере. Чтобы они работали с настоящей базой, в `.env` должны быть `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`, без них - с локальной `data/tiza.db`.

```bash
npm run admin -- list
```

Все логины.

```bash
npm run admin -- recovery <логин>
```

Новый ключ восстановления, если учитель потерял и пароль, и ключ. Ключ передайте учителю лично: по нему он сам задаст новый пароль.

## Что уже работает

- Ученики: стартовая страница со списком, у каждого ученика дорожная карта из тем.
- Учеников и темы можно переименовать и удалить (карандаш и корзина у строки).
- У каждой темы своя доска; статус темы (впереди, сейчас, пройдено) выбирается из списка.
- Рисование линий мышью, пальцем и стилусом.
- Цвета мела: три основных и четвёртый из коробки мелков (клавиши 1-4), коробка из 60 оттенков и свой цвет.
- Толщина мела: пять размеров, ползунок, клавиши [ и ].
- Текст (клавиша T): кликни и пиши; двойной клик указкой по надписи - переписать.
- Ластик (клавиша E): аккуратно стирает часть линии, текста, фигуры или картинки.
- Отмена и возврат: Ctrl/⌘ + Z, Ctrl/⌘ + Shift + Z.
- Учётные записи учителей: логин и пароль, ключ восстановления, смена пароля; ученики, темы и доски хранятся на сервере и открываются на любом устройстве.
- Сдвиг доски: колесо, пробел + мышь; масштаб: Ctrl/⌘ + колесо, сброс Ctrl/⌘ + 0.
- Полка внизу: указки, мелки с ластиком, что вставить, тетрадь; кнопки отмены и масштаба.
- Светлая тема (бумага) и тёмная (школьная доска): кнопка с луной или солнцем.
- Картинки и скриншоты: Ctrl/⌘ + V, перетаскивание файла или кнопка на полке; указкой (V) их можно двигать, менять размер (с Shift - свободные пропорции) и удалять.
- Задания из Word (.docx): каждое задание или пункт нумерованного списка становится карточкой на доске.
- Лазерная указка: зажми правую кнопку мыши; след быстро гаснет и виден ученику.
- Выделение участка (клавиша S) и удаление выделенного клавишей Delete.
- Ящик с фигурами: основные, геометрия, математика и объёмные; у фигур цвет, толщина, пунктир, заливка и доли.
- Живая доска: линии, фигуры и перетаскивание видны другому человеку сразу, пока их рисуют.
- Тетрадь: листы-рамки на доске и скачивание в PDF.
- Несколько серверов с запасным; по клику на значок связи видно сервер, задержку и на доске ли ученик.
- Указатель другого человека на доске с его именем и метка у края экрана, если он далеко.

Пока только для компьютера: телефон не поддерживается.

## Структура

Три страницы:

| Страница | Адрес | Файлы |
|---|---|---|
| Мои ученики | `/` | `index.html`, `src/home.ts` |
| Ученик и его дорожная карта | `/student.html?id=andrey` | `student.html`, `src/student.ts` |
| Доска темы | `/board.html?student=andrey&topic=…` | `board.html`, `src/board.ts`, `src/board.css` |
| Дорожная карта у ученика (по ссылке учителя) | `/roadmap.html?key=…` | `roadmap.html`, `src/roadmap.ts` |
| Доска у ученика | `/board.html?room=…&map=…` | те же, что у доски темы |

Общее:

- `src/students.ts` - хранение учеников и тем; `src/account.ts` - список учеников на сервере и ссылка входа.
- `src/notebook.ts` - тетрадь: листы и PDF.
- `src/base.css` - цвета светлой и тёмной темы и шрифт для всех страниц; `src/pages.css` - оформление страниц учеников.
- `src/theme.ts` - переключение и запоминание темы.
- `src/images.ts` - чтение и уменьшение картинок для доски.
- `src/tasks.ts` - задания из Word.
- `src/shapes.ts` - фигуры из ящика.
- `src/ops.ts` - изменения доски, общие для браузера и сервера; `src/sync.ts` - связь доски с сервером.
- `server/index.ts` - сервер: у каждой доски своя комната; `server/store.ts` - сохранение досок в базе.
- `src/row-actions.ts` - кнопки «переименовать» и «удалить» в списках.

- `vite.config.ts` - сборка всех трёх страниц.
- `.github/workflows/pages.yml` - после каждого пуша в master сайт собирается и выкладывается на GitHub Pages.
- `prototype/tiza-prototype.html` - кликабельный прототип будущего интерфейса.
