# Tiza

Онлайн-доска для уроков: учитель и ученик рисуют на одном холсте и видят действия друг друга.

Текущая версия: **0.3.0**. История изменений: [CHANGELOG.md](CHANGELOG.md).

Репозиторий: https://github.com/Maestro-Lumis/Tiza

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173.

## Что уже работает

- Рисование линий мышью, пальцем и стилусом.
- Три цвета мела: клавиши 1, 2, 3 или клик по мелку внизу.
- Губка (клавиша E): стирает линии, которых коснулась.
- Отмена и возврат: Ctrl/⌘ + Z, Ctrl/⌘ + Shift + Z.
- Доска сохраняется в этом браузере и остаётся после перезагрузки.

## Структура

- `index.html` — страница с холстом, мелками и губкой.
- `src/main.ts` — рисование, губка, отмена, выбор инструмента и сохранение.
- `src/styles.css` — оформление.
- `prototype/tiza-prototype.html` — кликабельный прототип будущего интерфейса.
