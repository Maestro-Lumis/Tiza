# Tiza

Онлайн-доска для уроков: учитель и ученик рисуют на одном холсте и видят действия друг друга.

Текущая версия: **0.0.0**, разработка только началась.

Репозиторий: https://github.com/Maestro-Lumis/Tiza

## Ближайшая цель

Работающая доска и рисование. Остальное (блоки, перемотка урока, ветки, карта обучения) потом.

## Структура

- `index.js` — точка входа (пока заглушка).
- `prototype/tiza-prototype.html` — кликабельный прототип интерфейса. Открывается в браузере как обычный файл.
