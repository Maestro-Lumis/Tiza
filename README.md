# Tiza

Онлайн-доска для уроков: учитель и ученик рисуют на одном холсте и видят действия друг друга.

Текущая версия: **0.5.0**. История изменений: [CHANGELOG.md](CHANGELOG.md).

Репозиторий: https://github.com/Maestro-Lumis/Tiza

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173.

## Что уже работает

- Ученики: стартовая страница со списком, у каждого ученика дорожная карта из тем.
- У каждой темы своя доска; статус темы: впереди, сейчас, пройдено.
- Рисование линий мышью, пальцем и стилусом.
- Три цвета мела: клавиши 1, 2, 3 или клик по мелку внизу.
- Губка (клавиша E): стирает линии, которых коснулась.
- Отмена и возврат: Ctrl/⌘ + Z, Ctrl/⌘ + Shift + Z.
- Ученики, темы и доски сохраняются в этом браузере и остаются после перезагрузки.
- Сдвиг доски: колесо, пробел + мышь; масштаб: Ctrl/⌘ + колесо, сброс Ctrl/⌘ + 0.
- Полка внизу: мелки, губка, кнопки отмены и масштаба.

Пока только для компьютера: телефон не поддерживается.

## Структура

Три страницы:

| Страница | Адрес | Файлы |
|---|---|---|
| Мои ученики | `/` | `index.html`, `src/home.ts` |
| Ученик и его дорожная карта | `/student.html?id=andrey` | `student.html`, `src/student.ts` |
| Доска темы | `/board.html?student=andrey&topic=…` | `board.html`, `src/board.ts`, `src/board.css` |

Общее:

- `src/students.ts` — хранение учеников и тем.
- `src/base.css` — цвета и шрифт для всех страниц; `src/pages.css` — оформление страниц учеников.
- `vite.config.ts` — сборка всех трёх страниц.
- `prototype/tiza-prototype.html` — кликабельный прототип будущего интерфейса.
